# An Explainable Fake News Detection Framework Using Fine-Tuned BERT with LIME

## Project Overview

This repository contains the implementation of my MPhil research project on explainable fake news detection. The project compares a traditional machine learning model (Logistic Regression) with a Fine-Tuned BERT model and uses LIME (Local Interpretable Model-Agnostic Explanations) to provide interpretable predictions.

---

## Objectives

- Detect fake and real news articles.
- Compare Logistic Regression and Fine-Tuned BERT.
- Improve prediction transparency using LIME.
- Evaluate model performance using standard metrics.

---

## Dataset

**Dataset Name:** WELFake Dataset

The WELFake dataset contains real and fake news articles collected from multiple online news sources.
